常规

翻译服务（Provider）

支持 OpenAI-compatible / DeepL / Azure / Google / 自定义 HTTP / 本地网关。翻译请求由后台统一发出，API Key 不会暴露给页面脚本。

编辑 Provider

直连本地 Ollama 时浏览器会带上 chrome-extension Origin。若测试返回 HTTP 403，请设置环境变量 OLLAMA_ORIGINS=* 后从托盘退出并重启 Ollama。本地端点无需 API Key，自定义请求头请留空。

custom-http 专属配置

DeepL 专属配置

Azure Translator 专属配置

native-host 专属配置（本地网关）

网关凭据保存在本机网关进程中，浏览器侧不保存任何后端密钥。

故障转移链（Failover）

活动 Provider 在重试用尽后仍失败（网络/超时/限流/服务端错误，或本地网关不可用）时，按此链条顺序接管。

术语表

术语表会注入到 System Prompt 的 {{glossary}} 变量；每次编辑自动递增版本号并使旧缓存失效。

站点规则

按域名匹配（支持 *.example.com 通配符）；多条命中时精确域名优先，字段按「显式 > 默认」合并。

本地网关（Native Host）

          

            网关是可选依赖：未安装时插件功能与 1.0 等价。安装方式见仓库 native-host/README.md
            （PolyPage.Gateway.exe --install）。
          

          

            
            
          

          

        


        

          
敏感网站黑名单

          
每行一个域名（如 mail.example.com），这些网站上不会执行翻译（含 iframe 与划词）。

          
        


        

          
PDF 双语阅读器

          

            在扩展内阅读器页中逐页翻译 PDF（本地 pdf.js 渲染，不修改源文件）。仅用户打开时翻译；
            段落缓存按文档指纹存储，重复打开零 API 调用。
          

          

            
          

          

            
            
          

          

            
          

          

            
            
          

          

            
            
          

          

            
          

        


        

          
图片文字翻译（OCR）

          

            只在用户点击时翻译图片（右键菜单 / 悬停按钮），绝不自动扫描页面图片。图片会降采样后
            发送给多模态视觉模型；费用与隐私由用户每次点击掌控。需要支持视觉的翻译服务
            （当前为 OpenAI-compatible 多模态）。
          

          

            
          

          

            
            
          

          

            
            
          

          

            
            
          

        


        

          
视频字幕翻译

          

            接管 <track> 字幕并在自绘字幕层显示双语（不修改视频源与字幕文件）。
            自绘字幕站点（如 YouTube）通过站点规则的 subtitleSelectors 适配，站点改版可能失效。
          

          

            
          

          

            
            
          

          

            
            
          

          

            
          

          

            
            
          

          

            
            
            
          

        


        

          
语音转写（无字幕视频 / 音频）

          

            用户点击后从当前播放位置采集有限窗口（默认 90 秒），经当前 Provider 的 transcribe
            或本地网关 Whisper 得到文本，再复用字幕层翻译。不申请麦克风；不自动转写整页。
          

          

            
          

          

            
            
          

          

            
          

        


        

          
浏览器兼容

          

            Chrome / Edge 为发行主线。Firefox MV3 临时加载可用网页六模式与划词；
            Native Host / PDF / ASR 若 API 缺失会置灰并在此说明，不会抛未捕获异常。
            详见仓库 docs/FIREFOX-MV3.md。
          

        


        

          
          
        


        

          
反馈日志（坏句标记）

          

            在双语块 / 字幕 / PDF 块 / 划词面板上「标记坏句」后记录于此（最多 200 条环形）。
            导出后可用于向 Provider 调优 Prompt。标记不改变页面渲染。
          

          

            
            
            
            
          

          

        


        

          
翻译缓存

          
缓存按「Provider + 语言 + 术语表版本 + 文本」存储在本机 chrome.storage.local。
